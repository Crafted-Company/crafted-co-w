# Crafted Co Design System
#test
## Philosophy

Crafted Co is not an agency.

Crafted Co is not a SaaS product.

Crafted Co is not a traditional portfolio.

Crafted Co is a digital workshop where ideas become products.

Every page should feel like entering a carefully crafted creative space rather than a marketing website.

The design should prioritize authenticity over conversion.

Visitors should leave with the impression that real things are being built here.

---

# Core Principles
sds
Design should feel

• Calm
• Premium
• Intentional
• Timeless
• Minimal
• Functional

Never flashy.

Never crowded.

Never corporate.

Every element must justify its existence.

# Color System

Background

Primary
Almost Black

Secondary
Deep Charcoal

Surface

Dark elevated panels.

Subtle separation.

No bright containers.

---

Accent Gradient

Inspired by the logo.

Electric Blue

↓

Deep Violet

↓

Warm Orange

Use gradients sparingly.

They should attract attention only to important elements.

---

Text

Primary

Soft White

Secondary

Muted Gray

Tertiary

Low contrast gray.

---

Status Colors

Avoid harsh colors.

Success
Muted Green

Warning
Muted Amber

Error
Muted Red

Never use saturated colors.

---

# Lighting

No glassmorphism.

No heavy blur.

Instead use

Soft glow

Subtle bloom

Gradient lighting

Very low opacity radial gradients.

---

# Borders

Thin.

1px.

Very subtle.

Slightly brighter on hover.

---

# Border Radius

Small

8px

Medium

16px

Large

24px

Do not use inconsistent radius values.

---

# Shadows

Soft.

Large blur.

Low opacity.

Never harsh.

Elevation should come from spacing before shadows.

---

# Spacing

Whitespace is a design element.

Prefer generous spacing.

Never cram content.

Use an 8-point spacing system.

---

# Grid

Desktop

12 columns

Max Width

1440px

Content Width

1200–1280px

---

# Typography

Display

Elegant serif.

Only for major headings.

Body

Modern sans-serif.

Readable.

Minimal.

Avoid decorative fonts.

---

# Buttons

Primary

Brand gradient.

Rounded.

Subtle glow.

Secondary

Transparent.

Border only.

Ghost

Text only.

# Cards

Cards should feel like physical objects.

Not floating windows.

Include

Large cover image

Comfortable padding

Subtle border

Minimal shadow

Hover elevation

---

# Icons

Consistent stroke.

No colorful icon packs.
