# Crafted Co — Database Schema & Storage Buckets (Revised)

This document specifies the Supabase database schema, table relationships, storage buckets structure, and API contract details for Crafted Co.

---

## 1. Tables & Relationships

### `categories`
Used to classify projects (e.g., Apps, Games, Websites, Experiments, Tools).
*   `id` (uuid, primary key): Unique identifier.
*   `name` (text, unique, not null): The user-facing name (e.g., "Game Development").
*   `slug` (text, unique, not null): URL-friendly string (e.g., "game-dev").
*   `created_at` (timestamptz, default `now()`).

### `projects`
Stores information about each project or product built.
*   `id` (uuid, primary key): Unique identifier.
*   `name` (text, not null): Project name.
*   `slug` (text, unique, not null): URL-friendly path identifier.
*   `category_id` (uuid, foreign key references `categories.id` on delete set null).
*   `short_description` (text, not null): Headline describing the project.
*   `full_description_mdx` (text): Full case study or description in MDX format.
*   `status` (text, check in `('completed', 'in_progress', 'paused')`).
*   `progress` (integer, check between `0` and `100`): Completion progress percentage.
*   `sort_order` (integer, default `0`): Manual ordering value.
*   `cover_image` (text): Storage URL to cover image.
*   `icon` (text): Storage URL to project icon.
*   `color` (text): Brand color or accent color hex/hsl.
*   `tech_stack` (text[]): List of technologies used.
*   `repository_url` (text): GitHub/repository URL.
*   `website_url` (text): Live production URL.
*   `playstore_url` (text): Google Play Store link.
*   `steam_url` (text): Steam game store link.
*   `featured_home` (boolean, default `false`): Highlights project on home page.
*   `featured_projects` (boolean, default `false`): Highlights project on projects page.
*   `search_text` (text): Combined text content generated/updated via triggers for full-text search.
*   `started_at` (timestamptz): Project start date.
*   `completed_at` (timestamptz): Project completion date.
*   `created_at` (timestamptz, default `now()`).
*   `updated_at` (timestamptz, default `now()`).

### `project_images`
Allows ordered gallery images with captions and alt text for projects.
*   `id` (uuid, primary key).
*   `project_id` (uuid, foreign key references `projects.id` on delete cascade).
*   `image_url` (text, not null): Storage asset URL.
*   `caption` (text): Optional visible description.
*   `alt_text` (text): Essential accessibility description.
*   `order_index` (integer, default `0`): Sorting index.
*   `created_at` (timestamptz, default `now()`).

### `project_versions`
Release and version logs for specific projects.
*   `id` (uuid, primary key).
*   `project_id` (uuid, foreign key references `projects.id` on delete cascade).
*   `version` (text, not null): Version identifier (e.g. `v1.0.0`, `Alpha 1`).
*   `changes_mdx` (text, not null): Details of additions, fixes, or improvements in MDX.
*   `released_at` (timestamptz, default `now()`).

### `journal_entries`
Log entries documenting the build process of projects.
*   `id` (uuid, primary key).
*   `project_id` (uuid, foreign key references `projects.id` on delete cascade): The associated project.
*   `title` (text, not null).
*   `slug` (text, unique, not null).
*   `excerpt` (text): Short preview summary.
*   `content_mdx` (text, not null): The body of the entry in MDX format.
*   `cover_image` (text): Lead post image URL.
*   `reading_time` (integer): Estimated reading time in minutes.
*   `pinned` (boolean, default `false`): Allows keeping critical posts pinned to top.
*   `visibility` (text, check in `('public', 'private', 'unlisted')`, default `'public'`).
*   `search_text` (text): Autogenerated text search searchfield.
*   `published` (boolean, default `false`).
*   `published_at` (timestamptz, default `now()`).
*   `created_at` (timestamptz, default `now()`).
*   `updated_at` (timestamptz, default `now()`).

### `journal_images`
Ordered gallery images for journal logs.
*   `id` (uuid, primary key).
*   `journal_entry_id` (uuid, foreign key references `journal_entries.id` on delete cascade).
*   `image_url` (text, not null).
*   `caption` (text).
*   `alt_text` (text).
*   `order_index` (integer, default `0`).
*   `created_at` (timestamptz, default `now()`).

### `tags`
Categorization keywords shared by both projects and journal entries.
*   `id` (uuid, primary key).
*   `name` (text, unique, not null).
*   `slug` (text, unique, not null).

### `projects_tags`
Many-to-many relationship mapping tags to projects.
*   `project_id` (uuid, foreign key references `projects.id` on delete cascade).
*   `tag_id` (uuid, foreign key references `tags.id` on delete cascade).
*   `primary key (project_id, tag_id)`.

### `journal_entries_tags`
Many-to-many relationship mapping tags to journal entries.
*   `journal_entry_id` (uuid, foreign key references `journal_entries.id` on delete cascade).
*   `tag_id` (uuid, foreign key references `tags.id` on delete cascade).
*   `primary key (journal_entry_id, tag_id)`.

### `timeline`
Tracks key project milestones (e.g. initial commits, major releases, version updates).
*   `id` (uuid, primary key).
*   `title` (text, not null): Milestone description (e.g., "Initial Release").
*   `description` (text): Contextual info.
*   `date` (date, default `current_date`): Event occurrence date.
*   `project_id` (uuid, foreign key references `projects.id` on delete cascade): Optional, can link event directly to a project.
*   `type` (text, check in `('commit', 'release', 'milestone', 'learning')`): Type of milestone.
*   `reference_slug` (text): Slug for matching detail routing.
*   `reference_type` (text, check in `('project', 'journal')`): Route discriminator.
*   `created_at` (timestamptz, default `now()`).

### `now_items`
Dynamic status feed entries for the "Now" page.
*   `id` (uuid, primary key).
*   `category` (text, not null): (e.g. "Currently Reading", "Currently Playing", "Learning").
*   `title` (text, not null): Specific item/status.
*   `description` (text): Optional context or comments.
*   `sort_order` (integer, default `0`): Manual priority sorting order.
*   `created_at` (timestamptz, default `now()`).

---

## 2. Storage Buckets & Folders

All media assets are stored inside a single `assets` public storage bucket, separated by logical prefix folders:
*   `projects/` — Cover images, icons, and layout renders.
*   `journal/` — Dev screenshots and post headers.
*   `avatars/` — Personal profile and banner pictures.
*   `misc/` — Document downloads.
