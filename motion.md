# Crafted Co Motion System

## Philosophy

Motion should communicate craftsmanship.

Animation exists to improve understanding.

Never animate for attention.

Motion should feel calm and confident.

---

# Motion Personality

Elegant

Fluid

Intentional

Soft

Natural

Responsive

---

Avoid

Flashy

Elastic

Cartoon

Chaotic

Overly playful

---

# Timing

Micro

150–250ms

Standard

300–450ms

Large transitions

500–700ms

Never exceed 900ms.

---

# Easing

Prefer spring physics.

Smooth acceleration.

Gentle deceleration.

Avoid linear animation.

---

# Page Transitions

Navigation should feel seamless.

Old page

Fade slightly

↓

Move upward

↓

Disappear

↓

Next page fades in

↓

Slides upward into place

Background remains stable.

---

# Scroll Animations

Reveal once.

Never replay repeatedly.

Use

Opacity

Translate

Slight scale

Never dramatic movement.

---

# Hover

Hover should communicate interactivity.

Allowed

Small lift

Glow

Border highlight

Image zoom

Text brightness

Tiny rotation

Avoid

Large scaling

Bouncing

Spinning

---

# Buttons

Hover

Glow increases

Gradient shifts slightly

Shadow softens

Press

Compress slightly

Release naturally

---

# Navigation

Current page

Animated underline

Smooth transition

Hover

Soft text brightness

Tiny underline animation

---

# Cards

Idle

Minimal border

Very subtle shadow

Hover

Lift

6–10px

Image

Scale

1.02–1.05

Border

Gradient glow

Arrow

Slides right

---

# Images

Fade in only once.

Never constantly animate.

Hover may

Zoom

Rotate 0.5°

Glow slightly

---

# Hero

Background gradients move extremely slowly.

Organic artwork gently floats.

Sparkle occasionally twinkles.

Movement should almost go unnoticed.

---

# Cursor

Interactive elements

Cursor changes smoothly.

Optional

Magnetic buttons

Cursor glow

Very subtle.

---

# Journal

Entries animate sequentially.

Stagger

60–100ms

Movement

20–30px

Fade

0→100%

No exaggerated motion.

---

# Loading

Skeleton UI.

Soft shimmer.

Avoid spinners whenever possible.

---

# Theme Switching

Colors transition smoothly.

250–400ms.

Never flash the page.

---

# Accessibility

Respect prefers-reduced-motion.

Disable decorative motion.

Keep functional transitions.

---

# Rule

If removing an animation improves the interface,

remove it.

Motion should support the experience,

never become the experience.
